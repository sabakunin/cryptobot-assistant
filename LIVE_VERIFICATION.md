# Проверка живого CryptoBot — 16 ноября 2026

Проверка использовала существующую зашифрованную сессию владельца и настоящий Telegram MTProto. Кнопки брались из текущих сообщений CryptoBot, их callback-данные не подставлялись вручную.

Подтверждено на реальном аккаунте:

- Открытие `/p2p` → «Купить» → USDT → СБП.
- Повторное нажатие текущей страницы «1» и получение изменившегося списка.
- Когда кнопки страниц исчезли, обновление через «Назад» → СБП; после обновления список снова показал страницы «1» и «2».
- Открытие объявления, извлечение цены, объёма, СБП, условий и возврат к объявлениям.
- Подготовка объявления с диапазоном: «Купить USDT» → «Макс.» → экран «Создать сделку» → возврат без создания.
- Подготовка фиксированного объявления: «Купить … USDT» → сразу экран «Создать сделку» → возврат без создания.
- Переход «Мои сделки» → «Все статусы» → «Активные». Пустой результат подтверждается только при всех типах, монетах, способах оплаты и датах.
- Запуск рабочего процесса с источником `userbot`, доставка настоящей карточки через очередь управляющего бота и отправка обновлённого меню владельцу. Режим уведомлений использует сохранённый владельцем диапазон. Автопокупка не включалась.

По живым ответам исправлены:

- Запятая как разделитель тысяч: `1,067.971965 USDT` означает `1067.971965`, а не `1.067`.
- Кнопка покупки без числа для объявления с диапазоном.
- Прямой переход к подтверждению для фиксированной суммы.
- Округление подтверждаемой суммы до целых рублей: цена × точный объём проверяются с точностью показанной суммы.
- Варианты «многозачность» и «многозадачка» в предупреждениях.
- Чтение изменений через события вместо лишних запросов истории; интервал между действиями и сохранение FloodWait при перезапуске.
- Явный выбор активных сделок вместо проверки всей истории.

Финансовая граница проверки: кнопка «Создать сделку» не нажималась. Создание, ответ продавца и отмена реальной сделки не подтверждены этим прогоном. Их обработчики проверены автоматическими тестами, но это не заменяет проверку финансовой операции владельцем. Оплата и выпуск криптовалюты программой не выполняются.

Локальные тесты не обращаются к Telegram. Этот отчёт описывает отдельную живую проверку, а не имитацию сервиса.

## Постоянная панель управления

На живом управляющем боте отправлено одно сообщение новой панели. Разделы курса, статистики и главная страница последовательно отредактировали тот же `message_id`; новых сообщений для переходов не отправлялось. Повторная доставка уже показанного содержимого не вызывала запрос к Telegram. Настройки торговли не менялись, создание и отмена сделок в этой проверке не выполнялись.
