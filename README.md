# CryptoBot Assistant 0.4.0 — Автохав

Пользовательский клиент CryptoBot для покупки USDT за RUB через СБП. Управление — в собственном Telegram-боте; несколько пользователей и аккаунтов имеют независимые настройки.

## Обновление существующего хостинга

1. Останови старый процесс. Сохрани базу, каталог данных и исходный `APP_KEY`.
2. Обнови код из ветки `main` или распакуй новый ZIP поверх исходников. Не заменяй `.env`, базу и ключи.
3. Запусти прежней командой `python main.py`. Используй один процесс/экземпляр приложения.
4. Открой меню бота любой старой кнопкой навигации или командой `/menu`. Для каждого аккаунта проверь курс, при желании задай минимум суммы и включи поиск.

Настройки и подключённые сессии сохраняются. После перезапуска поиск выключен до нового подтверждения. Прежние режимы уведомлений и симуляции убраны из управления. Старый диапазон уведомлений не переносится в курс покупки автоматически.

## Управление

- **Запустить / Приостановить** — включает Автохав с подтверждением или прекращает новые попытки. Уже открытая сделка сохраняется.
- **Курс** — максимальная цена одного USDT в рублях, включительно.
- **Мин. сумма** — необязательный минимум полной суммы покупки в рублях. `0` или «Без минимума» отключают фильтр. Например, `5000` пропускает сделки с окончательной суммой меньше 5000 ₽. Покупается весь доступный максимум.
- **Сделка** — статус, проверка в CryptoBot и кнопка отмены с подтверждением. После подтверждённого закрытия поиск продолжается, если его не остановили.
- **Аккаунты** — подключение через QR/2FA, выбор аккаунта для настройки и остановка всех аккаунтов. Остальные аккаунты продолжают искать независимо.
- **Доступ пользователей** — заявки на доступ и разрешения по Telegram ID; раздел доступен владельцу.

Одна обновляемая панель вместо копий меню. Навигация работает и со старых кнопок; подтверждения запуска и отмены проверяются на актуальность. `/start` нужен для первой заявки на доступ; для обычного управления его повторять не требуется.

Условия продавца приходят вместе с результатом создания. «Многозадачность» выделяется предупреждением и сама по себе не исключает объявление. Оплату пользователь выполняет самостоятельно. Поиск проверяет только первую страницу USDT/RUB/СБП и допускает одну активную сделку на аккаунт.

## Скорость и восстановление

Команды обрабатываются независимо от отправки уведомлений. Панели пользователей получают приоритет в очереди. Повторный push неизменившейся страницы не вызывает прежнюю дополнительную паузу и чтение истории. Маленькие объявления пропускаются в списке, когда отображаемого объёма достаточно для уверенного исключения; окончательная сумма проверяется перед созданием.

Закрытые ID сохраняются отдельно для каждого аккаунта. Повторное или запоздавшее сообщение не возвращает отменённую сделку в активные. Если сообщение пропало или отмена пришла без ID, выполняется сверка. Неопределённый исход создания автоматически не повторяется.

## Установка

Python 3.12+. Установка зависимостей: `python -m pip install -r requirements.txt`. Запуск: `python main.py`. Dockerfile также запускает `main.py`.

Основные настройки окружения:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен управляющего бота |
| `ADMIN_USER_ID` | ID владельца, который одобряет других пользователей |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | Данные приложения Telegram |
| `APP_KEY`, `WEBHOOK_SECRET` | Исходные ключи установки; не менять при переносе базы |
| `DATABASE_URL` / `DATA_DIR` | Постоянная база или постоянный каталог данных |
| `BOT_TRANSPORT=polling` | Получение команд без webhook |
| `MONITOR_SOURCE=userbot` | Навигация по CryptoBot |
| `LIVE_TRADING_ENABLED=true` | Возможность включить Автохав; запуск подтверждается в боте |
| `PUBLIC_BASE_URL` | HTTPS-адрес приложения для QR/2FA Mini App |
| `REFRESH_SECONDS=1` | Целевой интервал начала проходов |
| `ACTION_INTERVAL=0.2` | Минимальная пауза между нажатиями |

Нужен постоянно работающий Python-процесс и сохраняемая база. Подробности установки: [HOSTING.md](HOSTING.md). В ZIP нет учётных данных. QR и 2FA вводятся в Mini App; пароль не отправляется сообщением в чат. Локально также доступны `python -m sniper auth-qr` и `python -m sniper auth`.

Ограничения Telegram имеют приоритет над заданными интервалами. После FloodWait выдерживается указанная сервером пауза. Произвольное уменьшение интервалов не гарантирует ускорение.

## Диагностика

`/menu` — управление; `/settings` — курс и минимум; `/accounts` — аккаунты; `/stop` — пауза; `/stopall` — пауза всех аккаунтов. `/status`, `/inspect`, `/diagnostics` помогают проверить состояние.

При неизвестном исходе операции `/trade D123456` привязывает ID для сверки. `/resolve` запрашивает ручное подтверждение отсутствия сделок, не отменяя ничего в CryptoBot.

## Проверки разработчика

```text
python -m pip install -e ".[dev]"
python -m pytest -q
python -m ruff check sniper tests migrations
python scripts/benchmark_responsiveness.py
```

Тесты используют имитацию Telegram и временные базы. Они не создают, не отменяют и не оплачивают реальные сделки. Новая версия проверена локально; скорость и поведение на уже работающем хостинге этим не измерены.
