# Доступ пользователей

Владелец из `ADMIN_USER_ID` всегда имеет доступ и управляет заявками.

1. Другой пользователь отправляет `/start` в личный чат с ботом.
2. Он получает «Заявка отправлена. Дождитесь ответа администратора».
3. Владельцу приходит имя, Telegram ID и кнопки **Разрешить / Отклонить**.
4. После разрешения пользователь получает меню, подключает свои Telegram-аккаунты через QR/2FA и задаёт собственные курсы.

Повторный `/start` не создаёт новую заявку. Группы и сообщения от ботов не принимаются. Отклонённый пользователь не может самостоятельно восстановить доступ.

## Управление

Если случайно отклонил заявку: открой `/users` и нажми **Разрешить** рядом с нужным ID. Старая кнопка заявки покажет актуальный список; действовать нужно свежей кнопкой. Выбранный торговый аккаунт не влияет на управление доступом.

- Кнопка **Доступ пользователей** или `/users`: заявки и список пользователей.
- `/allow 123456789`: разрешить существующую заявку по ID.
- `/deny 123456789`: отклонить.
- `/revoke 123456789`: отозвать доступ.

При отзыве останавливаются поиск и подключения пользователя. Открытые сделки сохраняются; их нужно проверить в CryptoBot. Повторное разрешение сохраняет настройки, но не включает поиск автоматически. Старые кнопки одобрения не возвращают отозванный доступ.

У каждого пользователя свои аккаунты, настройки, меню, история, уведомления, активные сделки и попытки QR/2FA. Пользователь не может управлять чужими аккаунтами. Один и тот же торговый Telegram-аккаунт нельзя одновременно привязать к разным пользователям. `MAX_ACCOUNTS` задаёт лимит аккаунтов на пользователя.

## Работа на ПК

Для QR/2FA с чужих устройств форме нужен HTTPS. На хостинге используй `PUBLIC_BASE_URL`. Для временного запуска на ПК можно указать в `.env`:

```dotenv
PUBLIC_BASE_URL_FILE=data/public-url.txt
```

И запустить два процесса из каталога приложения:

```powershell
.\.venv\Scripts\python.exe -m sniper.local_tunnel
.\.venv\Scripts\python.exe -m sniper serve
```

Модуль `local_tunnel` использует установленный OpenSSH и бесплатный [localhost.run](https://localhost.run/docs/forever-free). Он обновляет адрес формы при смене домена и переподключается при обрыве. Бот читает адрес без перезапуска. После смены адреса старую форму нужно открыть заново через `/start` → «Аккаунты». Пароль 2FA вводится в форме, а не сообщением в чат.

Бесплатные адреса временные; ПК и оба процесса должны оставаться включёнными. Для постоянного адреса используй хостинг с HTTPS и отключи `PUBLIC_BASE_URL_FILE`.

## Обновление

Сохрани базу и исходный `APP_KEY`, останови старый процесс и обнови код. Существующие настройки и сессия становятся профилем владельца. Заявки и разрешения сохраняются в зашифрованной базе. Отдельная миграция SQL для этой версии не требуется.
