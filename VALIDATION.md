18 ноября 2026. Исходная версия репозитория — `9cf69a2` (0.3.3). Настоящие торговые операции в этой проверке не выполнялись.

## Результат

- Полный набор: **235 passed in 37.93s** на Windows / Python 3.12; исходный набор 0.3.3 — 197 тестов.
- `ruff check sniper tests migrations scripts` — без ошибок.
- `git diff --check` с учётом существующих CRLF-файлов — без ошибок.
- Собран wheel 0.4.0; веб-ресурсы QR/2FA включены.
- Распакованный ZIP запущен через `python main.py` на случайном локальном порту, с временной базой и поддельными реквизитами. `/healthz`, версия 0.4.0 и ресурсы Mini App доступны; неавторизованные API-запросы отклонены. Ключи созданы в постоянном каталоге тестового процесса.
- При тестовом запуске `MONITOR_SOURCE=off`, `BOT_TRANSPORT=webhook`, реальное исполнение выключено. Сетевых обращений к Telegram не было; процесс завершён после проверки.

## Существенные сценарии

Повтор отмены и запоздалое сообщение об открытии не возвращают закрытую сделку в активные. Отмена без ID принимается только на известном сообщении сделки; новый текст без ID вызывает сверку. Исчезновение сообщения проверяется по списку активных сделок. Чужая сделка и цитата продавца не снимают блокировку. Неопределённое создание остаётся заблокированным.

Проверены окончательная сумма ниже минимума, точная граница, отсутствие минимума, выключение минимума во время поиска, изменение фильтра между подготовкой и созданием, округление объёма, пропуск маленького объявления без открытия, разделение минимумов и закрытых ID между аккаунтами.

Проверены сохранение команды при заблокированной отправке и подтверждении callback, устаревшая очередь панелей, старые кнопки навигации, повторные нажатия, контроль актуальности подтверждений, отзыв доступа, сохранение изоляции пользователей и аккаунтов. Длинные условия сохраняются полностью и делятся с учётом лимита UTF-16 Telegram.

Сохранены проверки цены, максимального объёма, потери соединения после возможного Create, потери блокировки процесса, запрета повторной покупки и отказа отменять оплаченную сделку.

## Производительность

Одинаковая имитация сети и настоящая временная SQLite, по три последовательных запуска каждой версии: обновление неизменившегося списка **521,54 → 15,28 мс**; обработка кнопки при занятой отправке **556,33 → 52,65 мс** (медианы). Методика и исходные результаты: [PERFORMANCE.md](PERFORMANCE.md).

## Границы результата

Хостинг пользователя не подключался. Реальная скорость Telegram, создание и отмена настоящей сделки, а также одновременная работа настоящих аккаунтов этим релизным тестом не проверялись. Автоматические сценарии используют поддельный клиент Telegram. Предыдущие отчёты `LIVE_*` относятся к старым версиям и не заменяют эту проверку.

Для установки нужно обновить код на текущем хостинге, сохранив базу и исходные ключи, и запустить один экземпляр приложения. После перезапуска поиск включается пользователем отдельно для каждого аккаунта.
